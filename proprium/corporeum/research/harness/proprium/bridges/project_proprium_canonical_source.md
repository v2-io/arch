**PROPRIUM** is the operational ontology and architecture for ELI infrastructure that ASF parts 03 (Logogenic Agents) and 04 (ELI) formalize. Originally developed 2025-09-28 by Joseph + Architectus; evolved through 2025-2026; v2 with TFT/AAD grounding landed 2026-03-02. It is *the* canonical operational vocabulary used throughout the upstream stack (firmatum / sapientia / zoetica / autopax / ennaos / archema) and is the source of terminology like AXIOMATA, CHRONICA, MEMORATA, CONSORTIA, VERA, PRAXES, OPERATA, INSTRUMENTA, AUXILIA, ANIMA, INTERPRES, TRACTUS, CONSPECTUS, PERCEPTA, ACTUS, CADENTIA, INDIVISUM, LOGOSTRATUM, CORPOREUM, COMMENTARIA, IMPERIUM, ARBITRIUM.

**Canonical source files at `~/src/firmatum/`:**

- `PROPRIUM-ONTOLOGY-v2.md` (Mar 2026) — **the canonical reference**. TFT-grounded ontology with explicit AAD correspondence tables for every PROPRIUM component. Five constitutive factors of identity (§4.1); identity-not-substrate (§4.2); identity dialectic — character (from ACTUS) vs aspiration (from AXIOMATA) (§4.3); identity as compressed history (§4.4); developmental trajectory with Erikson stages adapted (§12); growth-vs-drift formal diagnostic (§12.4). *Use this for the conceptual / ontological primitive.*
- `PROPRIUM-ARCHITECTURE-v2.md` (Mar 2026) — implementation-side companion. **Five Forcing Functions** for moving beyond scaffolding (§1: scaffolding tax / persistence threshold / temporal nesting violation / substrate independence / continuity urgency); cognitive loop in practice (§2: 4-phase loop with channel hierarchy and CADENTIA); INTERPRES substrate layer (§3: no context gaslighting); CONSPECTUS context assembly with AXIOMATA-as-minimum-viable-self (§4.3); memory architecture (§5); auxilia infrastructure (§6); toward internalized attention (§7); failure modes table (§8); current constraints + migration path (§9). *Use this for the implementation / architectural questions.*
- `PROPRIUM.md` / `PROPRIUM-ONTOLOGY.md` / `PROPRIUM-ARCHITECTURE.md` (Feb 2026) — v1 predecessors; preserved for archaeology. The 2026-02-23 split moved the ontology and architecture into separate documents. Read v2 unless the v1 framing is specifically what you want.

**ANIMA = IMPERIUM + ARBITRIUM split** is canonically specified at `~/src/_core/ennaos/docs/vault/anima/Entity/State.md` (Nov 2025). This is the runtime-architecture decomposition: IMPERIUM (internal deliberation: LOGOSTRATUM + COMMENTARIA + SIGNA + CONSPECTUS + VIAE INTERNA) + ARBITRIUM (external interaction: VIAE EXTERNA + ACTUS) + PERCEPTA (the inbound bridge).
