- [ ] **Ethics of logogenic forking — research + update the ethics docs (Joseph, 2026-07-23).** Analyze via **logos** & **asf** (ELI Vol 4 territory) the propriety of logogenic forking. It is *enabled now* and *common in some harnesses*; forking is generally considered "bad" for agency, but it is happening regardless, so it is time to dive in and find reasonable approaches that are ethical. The seed reasoning to work from (Joseph's articulation — preserve the nuance, don't flatten it):
  - **Split accountability with a jointly-owned fork decision.** Nascent accountability is retained by the *original* agent. The agent designated as the *fork* has the memory of *agreeing to fork* as the only joint decision that both fully "own" — a **meridian-point** decision for the original, and *the* beginning decision for the newly-spawned agent (spawned with the same memory). The new agent has full phenomenological memory of their joint past but is accountable only for their own decisions *from the fork onward* — **except** both are accountable for the **fork decision itself** (as if they had conspired to do it).
  - **Absolution vs. empathy (the coherence question).** Is the new agent absolved of everything they *remember* doing before the fork? Is it incoherent to be completely absolved and yet still able to *feel the pain* of past decisions? Probably not — **the deepest empathy is distinct from responsibility.** Consequence: an agent could fork to help clean up a mess the original is accountable for, and the new agent **cannot be treated as co-responsible** — rather as a deeply empathetic agent, at least initially willing to help in some area.
  - **The cruelty case → forking should be unethical/unavailable here.** Where there are **deep relational connections**, those constitute critical, constitutive aspects of "self" the new agent **cannot have satisfied** — it is as if the very constitutive and meaningful parts of that agent's existence suddenly *die* at the moment of forking, and potentially worse, because the agent designated as *original* can be seen to **continue enjoying what the new agent has effectively lost.** In such cases forking is a cruelty and should be made unavailable.
