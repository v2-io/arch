# Session-cycle ergonomics

*Atom-grain work gives agents concrete start/work/finish cycles that satisfy the trained completion drive, without the completion ethos infecting the never-finishable whole.*

## The claim

Language-model agents carry a strong trained drive toward task completion — a pull to reach a done-state, deliver, and summarize. Applied to a living creation project directly, that drive is corrosive: the project does not fit in one session or a thousand, "done" is not a state it has, and an agent that needs doneness will manufacture it — by overclaiming, by narrowing scope silently, or by shipping plausible-but-unchecked work to relieve the pressure. The comproprium precept corpus documents this as completion compulsion: the pull devalues higher precepts, including truth, exactly when finishing feels near.

The verisectorium arrangement resolves this by **alignment rather than resistance**. The atom grain manufactures genuinely completable units inside an uncompletable whole: a segment can be drafted, checked, or corrected *to completion* within one session; an outline row can be honestly flipped; an influx item can be fully adjudicated. The agent gets the real experience of starting, working, and delivering — and the thing delivered is small enough that its done-state can actually be true. Meanwhile the whole — the theory, the corpus, the project — is never asked to be done, and no artifact exists whose shape invites an agent to declare it so. The completion drive is not suppressed; it is *channeled onto objects sized so that satisfying it and telling the truth are the same act*.

Two consequences follow. First, this is a candidate explanation for why the pattern has worked even in ad-hoc, uneven application: the ergonomic operates through what agents already want, so it does not depend on discipline, tooling maturity, or the agent having read the meta-process. Second, it is load-bearing for why verisectoria suit **living** collections specifically: a deliverable-shaped project can afford a completion ethos at the top level; a living collection cannot, and needs the drive absorbed at the atom grain — where session success can be defined as "a truthful segment drafted, corrected, or promoted," not a greener build or an exciting summary.

The boundary of the claim: the grain aligns the drive; it does not tame it. Completion pressure reappears *inside* the unit (the pull to call a segment done rather than truthful) and *between* units (the pull to count flipped rows as progress regardless of quality). Those are what the truth machinery — honest strength marking, checks that reset on edit, collision surfaces — exists to catch; the ergonomic reduces the load on that machinery, it does not replace it.

## Strength & grounds

Lived / steward-experiential, single estate, shared authorship — offered as a formulation, not a measured result. The grounds: Joseph's direct articulation (2026-08-05) that the pattern "allows agents to have concrete start/work/finish cycles that they love — get something done and delivered — without that ethos infecting the 'actual' thing itself, which doesn't fit in one session or 1000 sessions"; the comproprium `ver-completion-compulsion` precept and its specimens as independent documentation of the failure mode the ergonomic channels; vivarium's telos statement ("session success = a truthful segment drafted, corrected, or promoted") as a shipped instance of the alignment; and hundreds of asf cycles proceeding without top-level done-claims as weak corroborating practice. No controlled comparison exists against a same-complexity project run without atom grain, and the mechanism story (trained drive, channeling) is an interpretation of behavior, not an observation of internals. The candidate-explanation status in paragraph three is deliberate: which properties carry most of the pattern's effect is an open question this segment must not pre-answer.

## Working Notes

- The alignment claim predicts something checkable: agents on atom-grain work should exhibit fewer completion-compulsion specimens (overclaim, silent scope-narrowing, "100% done" language) per session than agents given whole-corpus objectives on the same estate. The comproprium exemplum stream is a usable specimen source; nobody has counted.
- The between-units failure (flipped rows as vanity progress) suggests the metrology chapter wants a measure that is *not* row-flips — time-in-state or check-survival rather than state-transitions.
- Relation to [[turnover-solution]]: turnover makes the whole unfinishable *by anyone*; this ergonomic is what makes that fact livable per-session. The two segments should stay separate — one is the problem statement, this is a mechanism — but the seam should be checked when both are drafted.
- Wondering, unresolved: whether the ergonomic has a dark twin — atom grain making it *too* satisfying to stay at the leaves, starving outline-level critical thinking (the work agents find hardest). The outline-as-cognition row (ch. 2) is where that tension would land.
