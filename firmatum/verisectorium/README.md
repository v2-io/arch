# Verisectorium

Working name (2026-08-05) for **outline + segments** structures: stable atoms (segments; slug = identity), an outline as exposition **view** (order, membership, view-local metadata), and epistemic state carried honestly per atom — the pattern that keeps establishing itself across this estate because it is a **solution to 100% agentic turnover in highly complex, living creation projects**.

The shape is portable across deployments (asf, vivarium, relata, comproprium, …). Atom kinds, type vocabularies, and enforcement profiles are per deployment. This project exists to understand the pattern from first principles and — derived from that foundation — deliver a standardized, customizable way to launch and manage instances.

## Telos (read first)

**Session success = a truthful segment drafted, corrected, or strengthened — or an open item honestly discharged.** Not files moved, not directories emptied, not a completion narrative. The corpus reports its own state (the OUTLINE's `State` column; the INFLUX index) — read those instead of narrating past them. Two laws govern every disposition: **the delete-test** (nothing is integrated unless all its information is landed or truly disposable — assume it disappears) and **proxy-discipline** (a register, an index, or an agent's report *locates* truth; it never settles it). When delegating: orient agents to this telos before the task — subagents optimize whatever finish-line they're handed, so hand them this one.
