# Influx — manifest

*The canon store's membrane: nothing writes `def/`, `src/`, or the outline directly — material lands here first, waits visibly, and crosses only through adjudication ( [[form-influx-membrane]]). This file is the manifest: any agent or person can find it and append to it, and an item is not really here until it has a row (a payload with no manifest presence is invisible work; a row with no payload is an unbacked claim).*

*At founding, this influx's primary content is the **base material** — the pre-instance substrate the instance draws its first segments from. Ordinary flows (steward drops, spike results, audit findings, cross-instance feedback) join it over time. Copies are reading substrate, never authority: segments draft from live sources, and originals win on conflict.*
