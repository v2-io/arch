# Outline-skipping failure

**Summary.** Agents repeatedly treat segment files as the primary entry surface and skip or under-use the outline; several instances treat this as a recurring, costly failure mode and have built gates or norms against it.

## Observation

**Documented as a known failure mode (not a one-off anecdote):**

1. **vivarium orientation gate** (INFLUX note 2026-08-05, from ORIENT.md / CLAUDE.md): agents treat claim segments like “docs you skim after coding” and jump to code; the gate exists because *feeling* oriented (especially post-compaction) is not the same as having walked the outline + starred claims. Free-read is defined as **outline first**, then starred rows in outline order.
2. **De-novo audit discipline** (asf / genericized INFLUX copy): the OUTLINE’s linearized order is a **verification target** (topological claim); skipping to “central” segments is explicitly a failure mode for missing load-bearing appendix material and dependency order.
3. **asf agents SOP / theory structure**: “Read `01-aat-core/OUTLINE.md` first” / ordering lives in OUTLINE — orientation defaults that exist because free-form segment browsing is the default temptation.
4. **Field report addendum**: comproprium `the-chain.md` and outline-first norms show the estate inventing **narrative** and **importance** overlays precisely because raw segment directories are not a usable front door.

**Cost (qualitative, named in sources):** wasted work on wrong segments; audit findings that miss dependency breaks; code/instrument work that is not claim-governed; post-compaction false confidence.

## Method

- Primary warrant: orientation-gate note + de-novo audit SOP language + asf orientation defaults.
- **Not** measured: frequency counts of skip events across sessions (no systematic log of “outline open rate”).

## Strength and scope

- Supports: **the failure mode is recognized often enough that multiple independent mechanisms were built against it**.
- Does not support: a frequency estimate; that every agent always skips; that outline-first is always optimal for every task type.
- Honest strength: **recurring qualitative pattern with engineered countermeasures** — stronger than anecdote, weaker than measured incidence.
