# Type vocabulary locality

**Summary.** Instances that share the outline+segment *shape* fill the type (or equivalent) column with domain-local vocabularies; portability of shape does not imply a single shared type enum.

## Observation

Side-by-side specimens (estate, 2026-08-05):

| Instance | Shared shape | Type / kind vocabulary (examples) |
|---|---|---|
| asf claim segments | OUTLINE tables + `src/{slug}.md` + FORMAT | postulate, definition, scope, result, derivation, discussion, … (~20 theory types in live FORMAT) |
| udon-needs tooling corpus | same table-ish outline shape | **demand**, finding, principle, method, counterposition, synthesis, … (sampled frontmatter 2026-08-05 under `udon-needs` / MOVED path) |
| comproprium | three directories + outlines | **principle / mechanism / observation** (vera); **probe / practice / protocol** (praxes); **account / testimony / quotation** (exempla) — by failure mode, not ASF types (live FORMAT) |
| neurips adjudicated | OUTLINE + claims/ + discussion/ | rung tags such as `[PROVED]`, `[REFUTED]`, `[JUDGMENT]` on claim rows (index genre, not ASF type enum) |
| paper-section lite (behavioral-floor, causal-language) | ordered `src/NN-*.md` | section roles (introduction, method, …), not claim-type vocab |

Compact form of the same observation (already stated in live asf-facing doc-store comparison of asf vs udon-needs): *the shape is portable; the type vocabulary is not, and should not be.* Live re-spot-check of udon-needs types above is consistent with that.

## Method

- Spot-read of frontmatter / FORMAT / outline rows across the instances listed; not a full census of every type token estate-wide.
- asf vs udon-needs type contrast also appears in the doc-store report’s OUTLINE+segments section (live under firmatum udon `to-integrate/…/doc-store-and-schemas-report.md` §12.2) — that report is analysis, not a claim store; the table above is the primary warrant for this obs.

## Strength and scope

- Supports: **at least these major instances use different type systems** under one family of arrangements.
- Does not support: that *no* shared spine of types can exist (comproprium still reuses ASF words when they fit); that type vocab must never be shared across two projects.
- Honest strength: **robust qualitative / multi-instance observation**, not a uniqueness proof.
