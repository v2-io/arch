# The language — the model as declarative rules

*Register: **sketch** — direction steward-offered, shape mine, nothing here syntax-final. The prose model (01–08) is this language's semantics; a deployment written in it is programmed and reinforced rather than prose-governed. Illustrative fragments are udon-flavored because that is the estate's config substrate, not a commitment.*

## What the language is for

The steward's founding statement of the want: a way to *"add a new 'rule' that adds a new state available to this 'line' under these conditions that enables this and this and this"* — a state-machine language for the logical writing chunks. Under RC1's model that resolves into a small set of **declaration forms** plus one **rule form**, because everything dynamic in the model is already events-under-guards:

- **declare dimension** — full name (namespace in the name), rungs in order, channels signed (which move up, which are refutation), ceiling law, movers (which event classes, performed by whom).
- **declare kind** — speech-act, fails-by, dimensions opened (or the foundation-declaration that derives them), write semantics, bounds carried (licenses, audience-safety, conflict-precedence).
- **declare edge-kind** — meaning, consumers, composability (transitive | chains-for-notification-only | never).
- **declare projection** — name, the trail-computation, and what its value licenses a consumer to do.
- **declare gate** — a standing validity condition (who may produce records of a kind; what may cross an emission seam).
- **rule** — the extension form: *when* (conditions over trail, edges, eras) *allow* (a state, a channel, a crossing) *enabling* (a license). Adding capability to a running instance is writing a rule, never editing prose.

Illustrative only:

```text
|dimension[evidence/in-vivo]
  :rungs    [pre-registered run-once swept independently-reproduced]
  :channels [first-run(era-keyed) sweep independent-re-run]
  :refutes  [prediction-miss]           ; signed; a miss is a recorded result
  :ceiling  exact-for-authored-world    ; every number era-keyed
  :movers   {run-events :by any-agent :criterion-commitment required}

|rule[allow-swept-serving]
  :when     (>= (rung evidence/in-vivo) run-once) (era-current sim)
  :allow    serve-as [empirical-within-era]
  :enabling cite-in-teaching build-on-at-risk
```

## The three properties that make it worth building

1. **Stating a securing act *is* recording it.** The under-recording economics (08) land here: when the language is the interface to the work — the run command emits the run event; the decision command writes the decision event — the trail-keeping tax goes to zero, and honesty's cost drops below dishonesty's. This is the inculcation ladder's bottom rung: the wrong act no longer expressible.
2. **The model's laws become lint.** Fusion is checkable (*no rule may define a state that is a cross-product of states movable by different rules*); substitution is unrepresentable (no rule may read one dimension's value into another's); hand-set status has no syntax at all. What the prose model polices by discipline, the language refuses to parse.
3. **Extension without drift.** A deployment's local delta is a visible rule with an author and a date — adjudicable, revertible, upgradeable — instead of prose divergence nobody can diff.
