# Claim: query-for-files empowers

Knowledge tools return paths (and enough locating context) rather than answers. Query-for-files empowers; query-for-answers constrains, slows, and can hallucinate.

A picture of a place is this claim applied to a tree: the seen-things, not a summary essay about them.
