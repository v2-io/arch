# Norm: a refusal offers a next action

Error-as-menu: offer candidates as ready-to-use exact next actions. A usage refusal points at `help`. A "not found" names a repair that is about the path, not about the flag set, unless the path looks like a flag.

Not bound: the three-field `mutated:` / `observed:` / `law:` schema (still an idea in the gather). Human text on stderr is the floor; the same object as JSON when `--format=json` exists.
