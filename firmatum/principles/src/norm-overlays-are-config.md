# Norm: estate overlays are config

Repo-file overlays are how estate law stays out of the baked binary. Adding a name to ignore, a furniture mapping, a pin — that is a config line, not a release.

Specimens: `.fmt-mdignore` → md-press; a locus overlay → aspectus (filename still open).
