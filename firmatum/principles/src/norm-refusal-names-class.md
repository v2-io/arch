# Norm: a refusal names the class

Name the failure class. "Not found," "not unique," and "resolves to several" are different situations with different repairs. So are "unknown option" and "unknown verb."

The class is first-class language, not a flavor of a single "error" string.

Not bound: the convention file's usage / input / runtime / config / permission taxonomy as a required set — useful axis, not a floor.
