# Formulation: help has a shape

Inline help carries, in this order: usage, what it is, commands, options, examples.

Not bound: the convention template's `-v`/`--verbose` line (verbose is not floor); man-page section list (the shape to follow *when* a page is written, not a gate on `--help`).
