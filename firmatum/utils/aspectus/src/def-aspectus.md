# Definition: aspectus

**aspectus** is the faculty of looking at a locus: the look itself, and the command that produces it.

You run `aspectus` *on* a locus. The path argument is how the command is given a place. The compound *locus-aspectus* is the concept when speaking PROPRIUM. The binary is only the half that is not already the path.

A **locus**, in PROPRIUM, is the location of action — project, sandbox, channel, environment, machine. It carries its own carta, praxes, operata, and so on. This tool does not implement a locus. It looks at one. Today that look is of the filesystem face of the place (the tree under the path). Other faces are not excluded by the name.

It is not **carta** (who the place *is*, standing identity). It is not **conspectus** (what a mind is shown — assembled context). It is not **percepta** (ongoing status and health). Those are neighbors. aspectus is how the place *looks right now*.

Latin is for a thing that needs a name. This earned it because the object is a kind of seeing, not a tree clone. `spectus` was an earlier candidate and remains a fair nickname. It is not the binary.
