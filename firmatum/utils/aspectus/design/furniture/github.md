# Furniture / GitHub

`.github/` is not a child of the look. It is specialized furniture (a plugin, not only a map row): the parent can say there is GitHub metadata here (workflow count, or just the kind) without listing hook samples and workflow YAML as the picture.

Same hide rule as Git. `--show-all` / `--inspect github` (or inspect of git — spelling open) lists it when you ask.

This is not network. It does not fetch. It does not decide `(private)`.
