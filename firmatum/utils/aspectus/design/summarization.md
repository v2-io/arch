# Summarization

When we stop expanding a directory (depth cutoff, later a line budget), leftover is **typed and honest**. Never `N unlisted`, never `…`, never a directory that looks finished and empty when it is not.

This row is the law. [[dir-census|Dir census]] is the leftover of an unexpanded directory. [[leaf-census|Leaf census]] is leftover files at a level (needs a line budget).
