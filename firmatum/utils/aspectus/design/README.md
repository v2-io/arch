# design/

**Aspectus-specific overlays only.** Not a copy of the principle corpus. A Part I story covered by Foundation may never get a file here.

Generic rows in [`../ASPECTUS.outline.md`](../ASPECTUS.outline.md) point at `../../principles/influx/…`. They move to `../../principles/src/` when decided for the suite. This folder gets a file when:

- a feature has **no** gather home and a decision must be recorded that is not already in the seeds, or
- aspectus **diverges** (copy-on-edit from influx/src), or
- aspectus is **additive** (a new outline row: `[[design/<nuance>\|<nuance>]]`).

Filename = slug = identity. Form-kind prefix only.

**Coding is not gated on a file here.** Seeds: [`../FEATURE-PIPELINE.md`](../FEATURE-PIPELINE.md), [`../IMPLEMENTATION-NOTES.md`](../IMPLEMENTATION-NOTES.md), the influx Tag.

Empty stubs are silt. If another util needs the same atom, it belongs in `principles/src/`, not here.
