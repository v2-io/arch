## 1. Principles from udon/v2 that transfer, and what they'd change here

- **Keep-everything, severity defined by loss** (RATIONALE). UDON never drops or halts; severity is *what was lost*, checkable, not vibes. Aspectus's honesty family (`≈ ≥ ~`, `[denied]`, `[walk bound]`) is the same idea one tool over — and the RATIONALE names the formal reading we've been circling: *"sharp, located, typed anomalies are low-ambiguity observations for agent consumers — the error channel is a teaching channel."* Consequence to consider: the walk's confessions are **anomalies with a location**, and JSON could carry them as one `anomalies: [{severity, where, what}]` list (UDON's `Document.anomalies` shape) instead of scattered booleans — one place to look for "what did this look fail to see."
- **Carve-outs carry their reasons.** UDON's rule: a deliberately-open question travels with the demand-side reason it is open, or a diligent agent closes it in a dead framing. Our design files have Open lists; most entries lack the *why-open*. Cheap fix, high value, exactly the failure this project had on 2026-08-14 (the `--visit` flag, the "stay children with tag" inheritance).
- **Headline density under line tools** (BEST-WITH-UDON): *one line carries identity + classification + state as readable structure, so grep answers real queries without a parser.* That is the cultivated-header idea stated as a property: the directory line **is** the `|decision[slug] :date :by :status` of a place. Test for any header design: can `grep` over a saved look answer "which repos are on a non-main branch?" — if the header's grammar is regular, yes.
- **Judged from first byte** — recognition is total; any input maps to a document. For aspectus: every node gets a row, and a row is never *malformed*, only *marked* — already true; worth stating as law so the grid refactor keeps it.
- **Designated, not reserved** (`$key` as an ordinary attribute the host quotes off). Transferable to config: the defaults file's `[layout]` lists and the glyph vocabulary are *designated* names the renderer recognizes; a user can add facts the renderer doesn't know (a Lua plugin's claim) and they ride the same grammar — one concept, not three.
- **Bounded lookahead as language law.** UDON declares the bound normative so streamability survives future syntax. Aspectus analog: *bounded reads* (the 1 KiB sniff, the 4 KB README peek, the read budget) are the law that keeps the glance a glance — say so where the filetype ladder is defined, so no future plugin slurps a file "just to check."

## 2. The bridge chapters, applied

- **tracking-snapshots-as-perception** — *"structured context-injection is perception design… the observation channels an embodied creature gets for free."* Aspectus is a perception channel, and the chapter's caveat is ours: *correlated channels overcount; a snapshot earns its tokens through independent signals.* Heat and recency-sort and mtime-quiet are **three renderings of one signal family** — the design already knows (the anti-collapse pair), but the defaults should be audited for redundancy the way the chapter says: which columns add independent bits for a cold reader? (The "declared perception budget" card is literally the `[layout]` section of the defaults file.)
- **context-economy** — a caller-declared token budget per call is the chapter's first capability card; aspectus already has the shape (`--lines`, `--walk`, `reads`). The gap it names: a `--caller` key that sets *all three* from the harness's known cap — the 30 KB tool-output cap the Fable instance hit this week. Also: *"capture, triage, and processing are separable; triage can read signal statistics without content"* — the walk's free readdir census **is** triage-without-content; the read budget is processing. Naming the stages would clarify what the walk bound vs the read budget each protect.
- **progressive-disclosure-read-path** — the glance conventions that "keep arriving": every payload carries **line numbers**; descent carries a **breadcrumb**; summaries as **counts in parentheses**; **confidence markers**; errors as **menus**. Aspectus has four of five (counts, marks, menus, the header-as-breadcrumb). The fifth — *what you can see is what you can address* — is the sharpest: a look's lines should be **valid addresses**. Today a row is a basename under a tree; an agent reconstructs the path. A `format.name = relative` per-row path (or JSON's missing `path` field, noted this week) would make every row copy-pasteable into the next command. Worth a row.
- **counter-register row 1** — the one *measured* result in that whole corpus: structured/aligned notation improved comprehension 100% vs 60% on three model families and **failed to reproduce on one, which read it slower.** This caps every alignment/glyph claim we make: the cold-read tests for glyph packs and the width experiment must run across families, and the defaults may need a per-family `--caller` overlay (the chapter's row 7: tool discipline varies by family in ways scale doesn't explain).
- **annotation-and-metacognition** — the report's own four registers (derived / evidenced / decided / proposed) "marked by hand for lack of a native form." Our `stat` column (✓ ↬ ⇥ ␠) and the design files' *decided / proposed / open* are the same hand-marking. Aspectus itself could carry one: a **provenance grade** on claims in the header (glob-matched vs verified vs declared-by-the-place) — the thing the cultivated header needs to be honest.

## 3. The cultivated header — seeds only (Joseph's brainstorm, held)

What the udon reading adds to his sketch: the designation is a **line-tool-queryable sentence** with a fixed grammar — `<org/name:branch Python Repo>` — built from graded evidence: **verified** (a plugin read the real thing: `.git` HEAD, `Cargo.toml` name), **matched** (a glob fired), **declared** (the place said so — [[place-wants-known|place-wants-known]]'s channel, lowest grade). A priority rule picks the lead noun (repo > vault > plain dir), the language adjective comes from manifests (verified) before suffix statistics (inferred), and remote/branch/dirty appear only when they are *surprising* (non-default branch, dirty, no remote) — the quiet law applied to identity. Everything that lost the priority contest demotes to a glyph or a two-letter tag, or vanishes. The header then needs exactly one test: can a cold agent answer "what is this place and what's odd about it" from the line alone?

## 4. Plugins (Joseph's LuaJIT thought, same day)

The procedural residue of project classification — read `Cargo.toml` for workspace members, `package.json` for the name, a `.sln` — is where a script earns its place; glob maps can't express it. Leanings, not decisions: design the **interface** first, language-agnostic (inputs: a dir's names + stat types + fired evidence + bounded reads on request; outputs: graded claims, supplement text, focus hints); prove it on three Rust plugins (git, github, one manifest reader); make any script a **pure function of its inputs** (no io/os/clock/network — sandboxed) loaded **only from the caller stack**, never the locus; then open the door — LuaJIT (tiny, LLM-fluent, neovim precedent; FFI build dependency, one state per walk worker) or WASM (sandboxed by construction, heavier). The risk to name: scripts make *heuristics-without-design* easier, which is this project's founding scar — the interface must force claims to carry their grade.

## 5. Smaller wanderings

- `aspectus` output as an **address space**: with rows as paths, `aspectus | grep dirty | cut …` becomes a pipeline — the Unix move the tool has been avoiding by being a picture. Both can be true if the picture's lines are addresses.
- The **width experiment** (agents' column-tracking across widths and families) and the **glyph cold-read** are one experiment design: a fixture look rendered at N widths × M glyph packs, a fresh agent per cell asked to read values off it, error rate per cell. One afternoon, one table, and it settles three open questions (width default, supplement wrap threshold, pack readability) with data instead of my introspection.
- The inbox footer is already a **"stay on the line"** for a tool; the tool could also *read* the inbox's tail on `aspectus config` and say how many unrouted entries wait — the tool pointing at its own debt.
