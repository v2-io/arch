# Denied

A directory or file the walk could not read or stat says so. It is never rendered as empty, plain, or absent — an unreadable directory that prints as a bare `secrets/` is a silent lie, the same class [[summarization|Summarization]] forbids at cutoffs.

```
├── secrets/  [denied]
```

`denied` is **a fact about the look, not the inode** (the lattice's phrase): the same place looked at by another caller may not be denied. It hangs on the name (INFO office), default ON, not quietable.

Scope: `EACCES`/`EPERM` on `read_dir` or stat, and any error that leaves the walk unable to say what is there (the render may carry the class when it helps: `[denied]`, `[unreadable: io]`). A denied directory contributes no census and no mass — and whatever aggregate its parent carries is marked incomplete (`≥`) the same way a [[walk-bound|walk bound]] marks it.
