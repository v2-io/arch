## What the binary does now

1. **Config-drift header** (item 10). After the stamp, before the root-facts line: one line naming every effective setting whose *value* differs from the built-in default, with its source. Example: `depth = 3 (user-home) · --lines 200 (flag)`. Flags use the CLI form; everything else is `key = value (source)`. Absent when nothing differs (never an empty line). Charges `--lines` like stamp/facts; `--explain-budget` names it. JSON: top-level `config_drift` array of `{key, value, source}`, omitted when empty. Help names it. Inventory row `config-drift` is now `✓` / built.

2. **`aspectus config` units** (item 17). The `won:` listing prints `heat.half-life = 7 commits`, `reads = 67108864 bytes`, `lines = 80 lines`, `walk = 10000 names`, `depth = 2 generations`. `aspectus config defaults` still dumps the file verbatim.

3. **`--inspect KIND` with nothing to inspect** (item 13). Stderr: `aspectus: --inspect git: nothing of that kind in this look`. Exit unchanged (the look succeeded). One line per asked kind that no node in the tree claims.

4. **Census / has noise** (usability 6/7). All-digit suffixes (`man.1`, `page.2`) fold into `other`. A has-count of zero files is not printed (`agents ≈0f` → `agents`). JSON keeps the numbers (`files: 0`, `other` bucket counts).

5. **File-as-PATH facts line** (item 14). Already the count cell with `𝓁` (no heading follows) and `heat …` from the count-cell slice. Left the renderer; pinned by `tests/overview.rs::file_root_facts_use_count_cell` and the existing `tests/columns.rs::file_root_facts_are_labeled`.

6. **`dirty<N>` porcelain** (item 16). Already per-repo-root: `git -C <that work tree> status --porcelain`. Not the look's root, not a subpath. Left the call; comment + `tests/git_furniture.rs::dirty_count_is_per_repo_root` (sibling repos, independently dirty, same counts when viewed from their parent). The hallway's `dirty<3>`→`dirty<4>` in one minute is the session committing, not a cwd leak.

## Calls made

- **Flags count as different-than-default when the value differs**, matching the design's leaning. `--lines 80` (restating the default) does not appear; `--lines 200` does. Env/flags that restate the default value are silent (value, not source, is the test).
- **Header spelling:** file/env/user-home as `key = value (source)`; flags as `--depth 3 (flag)`. Source word is `flag` (the example), not `flags`. `--caller grok` is included when set (the design's "whose eyes" specimen). `--no-one-fs` / `--dotfiles-first` use the CLI form.
- **JSON field name `config_drift`.** Honest: it is the settings that drifted, not "config" in general.
- **Serialization `format` (text/json) is not drift.** Same look, two channels — a JSON document of the same tree must not claim different eyes than the text look (`design/json.md`).
- **Maps (`furniture`, `kinds`, `important`) are not on the header line.** They are not one-line eye settings, and a furniture overlay in the header collides with the look (`.mystery` in the drift line is not a child named that). They stay on `aspectus config`.
- **Equal bools compare semantically** (`true`/`on`). Alias keys (`format.size` / `format.bytes`) emit whichever actually differs.
- **`--inspect` "in this look"** means some node claims the kind on `[has: …]`. Mark-only kinds (already visible) count as present; a kind that isn't in the tree at all gets the stderr line.
- **Unbuilt `format.mtime` values (`signa`, `rfc-3339`, `pattern`) degrade to relative** rather than refusing the look. See flagged.

## Flagged (not this slice's to decide)

- **Concurrent `defaults.toml` change while this slice ran.** `format.mtime = "signa"` (unbuilt) and `format.heat = "density"`, far-left `["heat", "git-status", "mtime", "bytes"]`, far-right `["lines", "age"]`, `far-left-gap = 2`. This binary does not paint signa or a heat-density block. Without the degrade-to-relative fallback, every isolated-XDG look refused (`got signa; … signa not built yet`). The fallback is a stopgap so the default look still exists; it is not an implementation of signa. The slice that starred those defaults owns the paint.
- **Config-drift inventory position** is still `near-right` (the unbuilt placeholder). The line actually sits in the header after the stamp. No `header` position in the enum; not invented here.
- **Layout lists that differ** do not appear on the drift line (arrays, not scalars). A user-home `[layout]` change that actually moves a column will usually show up as a `columns.*` value difference; a reorder of the same membership may not.
- **Tight `--lines` tests** now pay the extra header line when the invocation itself differs from default. Bumped the ones this slice broke; the charging is the feature.
