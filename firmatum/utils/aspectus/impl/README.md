# impl/

Worklogs for Part I stories. Filename = the story slug (`absorb`, `allocator`), **not** a `form-` prefix. `form-` is a principle form-kind. These files are finish notes for this crate.

Create a file when there is a DAG, a blocker, a claim, or a finish note. `Todo: —` on the outline until then.

Not present-truth of the design — that is [`../design/`](../design/) or the Foundation pointer. These notes say what the binary did when the row landed.
