5. **Version `+sha` never moves across dirty rebuilds** — can't tell which look-language you're talking to. Add dirty marker/embedded build stamp.
6. Heat glyph confusions: `0.35` first read as a size; score=commit-clock but age=mtime-clock on one cluster ("two different clocks on one glyph"); blank heat drifts columns; scores >1 surprise.
7. `.claude`/`.archive` hidden is "a self-own" for agent callers — furniture fates want caller-kind awareness (the `--caller` mechanism exists; no agent default map yet). `memorata.egg-info` missing from the map.
8. Help drift: "unbuilt keys refused by name" already false for `--sort heat`; the moving-essay problem is the version-stamp problem.
