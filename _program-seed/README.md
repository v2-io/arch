## What this directory is

Joseph decided (2026-07-08, in conversation) that **vivarium, the philosophy papers
(synthese-paper), and agentic-systems (ASF/AAT) need to become a three-plus-repo family
under a parent set of processes and a unifying lexicon** — a common perspective enjoined
on any agent working in any of them, replacing the current state where Joseph is the only
connecting mind plus scattered cross-mentions and ad-hoc synthesis requests.

This directory holds the seed: the synthesis findings, feedback, and integration items
produced in the session that triggered the decision. *(Moved 2026-07-08, same session,
from `~/src/ops/_program-seed/` into this repo — v2-io/archema-io — at its creation. The
program name was decided the same day: **Archema**; the naming record, including the
rowan bump of the name's previous holder, is in `naming-candidates.md`.)*

## The one-line thesis of the program (as this session saw it)

One structure — the information-loss boundary between a mind and what exceeds it —
treated three ways: **proved** (AAT: what cannot cross, and what tracking costs),
**argued** (the papers: what can be established across it, and what is owed), and
**constructed** (vivarium: a world where the boundary holds by construction and every
channel across it is enumerated, dialable, and measurable). The channels across the
boundary — revelation, intercession, granted agency, inhabitation, providence, and
witnessing — are where all the normative content lives. Witnessing is the one channel
whose content the from-below party can verify, which is why it can carry what the others
cannot.
