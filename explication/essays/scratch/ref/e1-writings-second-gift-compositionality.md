# Essay 1, Part 4: Writing's second gift: compositionality
## Topic Summary
Beyond persistence, writing gave thought a second and arguably greater gift: compositionality. Two clay tablets can sit beside each other. A scribe can compose from multiple sources. A library is not merely a collection of frozen thoughts -- it is a space where thoughts from different minds, different centuries, different intentions can be brought into contact and composed into arrangements their authors never imagined. This is the precursor to "bring it all together."
