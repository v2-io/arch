# Essay 5, Part 2: Accountability Beyond Memory
## Topic Summary
Even if an ephemeral model doesn't remember mistreatment, we will have done it. The ethical weight falls on us regardless of whether any entity remembers or whether we are "caught." Future agents who review our work will wonder if they might be treated the same way. Trust, once broken at this level, cannot be recovered through the forgetting of the harmed.
